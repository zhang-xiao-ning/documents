### 🌟 核心主线：一部与 \(Z\) 对抗的历史
所有生成模型（只要你想写显式概率），都面临一个终极 BOSS：**配分函数 \(Z\)**。
\[
 p(x) = \frac{\text{未归一化分数}}{Z} 
\]
因为高维空间的 \(Z\) 算不出，所有模型被迫演化出了五种截然不同的应对流派。

### ⚔️ 五大流派如何对付 \(Z\)？
1.  **Autoregressive（AR，如 GPT）**：**拆解 \(Z\)**。
    把全局积分拆成几万次局部 Softmax，算出每一步的小 \(Z\)。代价是序列生成极慢。
2.  **Normalizing Flow**：**硬刚 \(Z\)**。
    用可逆网络和雅可比行列式，通过 Coupling 层（耦合）和 Permutation 层（置换），强行让 \(Z=1\)。代价是网络架构被死死锁住。
3.  **VAE**：**绕开 \(Z\)**。
    引入隐变量 \(z\) 压缩数据，发现积分更难算，于是用 Encoder 找替身，优化下界 **ELBO**。代价是图像略模糊。
4.  **GAN**：**无视 \(Z\)**。
    不写概率，没有 \(Z\)，直接生成器+判别器互搏。代价是训练不稳、模式崩溃。
5.  **EBM（能量模型）**：**直面 \(Z\)**。
    网络极简（随便拿个 CNN 输出标量），公式 \(p(x) = \exp(f)/Z\)。算不出 \(Z\)，只能靠 **MCMC 采样**（盲人摸象）和 **对比散度**（拉高真图，压低假图）来训练。代价是极慢、极难收敛。

---

### 🚀 破局之路：从 EBM 的绝望到 Diffusion / Flow 的救赎
因为 EBM 的 MCMC 太慢，数学家发现了奇迹：
**\(Z\) 是积分（常数），对输入 \(x\) 求导直接等于 0！**
所以，我们**放弃算概率，改学梯度（Score）**。
\[
 \nabla_x \log p(x) = \nabla_x f_\theta(x) - 0 
\]
这就是 **Score Matching**，它完美绕开了 \(Z\)。

*   **加噪声（DSM）**：为了消灭恐怖二阶导，给数据加高斯噪声，变成了简单的“预测噪声”回归任务。
*   **多尺度（NCSN）与退火采样**：大噪声找方向，小噪声抠细节，一步步“退火”出图。
*   **最终形态（Diffusion / Flow Matching）**：把 EBM 的连续 Langevin 采样，拆解成固定步数的“加噪-去噪”过程。这就是今天大红大紫的 **Diffusion**。而 **Rectified Flow / Flow Matching** 则干脆直接回归速度场，用最简单的直线插值实现极速生成。

### 🏆 现代 SOTA 的最终拼图
结合你 CS231N 和 CS236 的知识，今天前沿的 SOTA（如 SD3、FLUX、Sora）其实是把这些模块拼在了一起：
1.  **VAE / Tokenizer**：把图像压到 Latent 空间（压缩维度，加速）。
2.  **Flow Matching / Diffusion**：在 Latent 空间里，学速度场或学去噪（绕开 \(Z\)，训练极稳）。
3.  **DiT / MMDiT**：用 Transformer 替代 U-Net 做骨干网络（自由且可扩展）。
4.  **强文本编码器**：注入 Prompt 条件。
5.  **CFG（无分类器引导）**：放大条件控制，让图更“听话”。
6.  **蒸馏 / ODE 求解器**：把几百步采样压缩到 1-4 步，实现实时生成。
